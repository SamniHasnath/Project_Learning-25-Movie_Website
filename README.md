# 🎬 Movie Website

A full-stack movie website built using:

- React + Vite
- Node.js
- Express.js
- MySQL
- JWT Authentication

---

# 🚀 Features

- User Signup/Login
- Browse Movies
- Search Movies
- Favorites
- Watchlist
- Admin Dashboard
- Responsive UI

---

# 📁 Project Structure

```bash
movie-website/
├── backend/
├── frontend/
└── README.md
```

---

# ⚙️ Backend Setup

```bash
cd backend
npm install
```

Create `.env`

```env
PORT=5000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=yourpassword
DB_NAME=movie_db
JWT_SECRET=secretkey
```

Run server:

```bash
npm start
```

---

# 🎨 Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
